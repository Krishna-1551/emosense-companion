# Concise collapsible admin dashboard

## What will change
- Keep the header, privacy label, alerts, and five summary metrics immediately visible.
- Organize all existing admin content into four collapsible sections: Safety & Support, Intelligence Systems, Analytics & Insights, and People.
- Show compact status and count badges in each closed section header so administrators can scan without opening everything.
- Open Safety & Support automatically when unresolved high-priority cases exist; otherwise start with Analytics & Insights open.
- Preserve every existing chart, filter, action, support flow, user table, demographic view, and privacy boundary.

## Visual direction
- Use the selected cyber-industrial accordion treatment while retaining the app’s semantic colors and existing dark theme.
- Add restrained chevron transitions and clear focus states; avoid decorative motion.
- Keep the layout usable on narrow screens with wrapping section summaries and touch-friendly headers.

## Validation
- Confirm all four sections open and close correctly.
- Confirm safety actions, user controls, charts, and engine tools remain reachable.
- Check the authenticated admin page at desktop and mobile widths and confirm the app builds without errors.
